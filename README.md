# Denis Ops Mini App

Мобильный прототип личной операционной панели для Telegram Mini App.

## Экраны

- Сегодня
- Проекты
- Вакансии
- Чек-ин

Данные в первой версии демонстрационные и явно помечены как примеры. Импорт из Asana не выполнялся.

## Запуск

```bash
npm run dev
```

Открыть: http://localhost:4173

## Проверка

```bash
npm test
npm run build
```
