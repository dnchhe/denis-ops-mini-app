# Denis Ops Mini App

Мобильный прототип личной операционной панели для Telegram Mini App.

## Экраны

- Сегодня: приоритетная задача, задачи дня, фокус недели
- Календарь: планы, дедлайны, оплаты и контрольные точки
- Проекты
- Вакансии и статус планового поиска
- Чек-ин
- Профильная статистика по нажатию на аватар
- Состояние за 7/30 дней: энергия, настроение, фокус, тревога и сон
- Утренний, дневной и вечерний чек-ин

Данные в первой версии демонстрационные и явно помечены как примеры. Импорт из Asana не выполнялся.

## Поведение задач

1. Показывается первая доступная задача по приоритету
2. После `Начать задачу` действия меняются на `Завершить`, `Пауза`, `Проблема`
3. Завершение требует подтверждения
4. После подтверждения появляется следующая задача

## Запуск

```bash
npm run dev
```

Открыть: http://localhost:4173

## Проверка

```bash
npm test
npm run build
```
